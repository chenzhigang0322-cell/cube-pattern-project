# 魔方纹韵 - 智能魔方与中国传统纹样创作平台

## 项目简介

这是一个将GAN智能魔方与中国传统纹样创作相结合的创意平台。用户可以通过转动智能魔方来控制画布上的纹样元素，创作独特的艺术图案，并使用AI生成创意设计作品。

## 功能特性

### 1. 中国传统纹样元素系统
支持8种经典纹样：
- **回纹** - 古典折线纹样，象征连绵不断
- **云纹** - 流动优美的云形图案
- **雷纹** - 方折连续的雷形纹样
- **如意纹** - 寓意吉祥如意的装饰纹样
- **方胜纹** - 双菱形相连的传统纹样
- **盘长纹** - 佛教八宝之一，象征永恒
- **万字纹** - 寓意万福万寿
- **连续纹** - 可无限延伸的几何纹样

### 2. GAN智能魔方连接
- 支持GAN 356 i3等智能魔方
- 使用Web Bluetooth API进行蓝牙连接
- 实时监听魔方转动事件

### 3. 数学映射系统
魔方各面转动对应不同的元素变换：
| 魔方面 | 变换效果 |
|--------|----------|
| U (顶面) | 水平镜像 |
| R (右面) | 顺时针旋转90° |
| F (前面) | 放大20% |
| D (底面) | 垂直镜像 |
| L (左面) | 逆时针旋转90° |
| B (后面) | 缩小20% |

### 4. 画布编辑功能
- 点击添加纹样元素
- 拖拽移动元素位置
- 实时编辑元素属性（旋转、缩放、颜色、透明度等）

### 5. AI创意生成
- 根据画布图案生成创意设计
- 支持6种应用场景：帽子、杯子、头像、T恤、海报、手机壳
- 可自定义生成提示词

## 安装步骤

### 1. 安装依赖

```bash
npm install
```

### 2. 安装 shadcn/ui 组件

```bash
npx shadcn@latest add button card badge tabs slider input label switch
```

### 3. 运行开发服务器

```bash
npm run dev
```

### 4. 打开浏览器

访问 http://localhost:3000

## 使用方法

1. **添加纹样**：点击左侧纹样卡片添加到画布
2. **连接魔方**：点击"连接魔方"按钮，在浏览器弹窗中选择你的GAN智能魔方
3. **转动魔方**：转动魔方的不同面，观察画布上选中元素的变化
4. **编辑调整**：在右侧面板调整元素的详细属性
5. **生成设计**：选择应用场景，点击"生成创意设计"

## 注意事项

- 需要使用支持Web Bluetooth的浏览器（Chrome、Edge等）
- 首次连接魔方时需要授权蓝牙权限
- AI生成功能需要配置API Key
